Hospital Database Management System (SQL)
Project Overview
A SQL-based project focused on managing hospital data and retrieving meaningful information through queries. The database includes doctors, patients, medicines, surgical items, appointments, and prescriptions.

Database Tables
•	Doctors: ID, Names, specializations, experience, and contact details.
•	Patients: Names, age, gender, and city.
•	Medicines: Names, categories, prices, and expiry dates.
•	Surgical Items: Equipment details, types, costs, and stock information.
•	Appointments: Patient–doctor relationships, dates, and statuses.
•	Prescriptions: Prescription records linked to patients, doctors, and medicines.
SQL Concepts Used
•	Database creation and data insertion
•	Schema modification using ALTER TABLE
•	Data filtering using WHERE, LIKE, and BETWEEN
•	Sorting and limiting using ORDER BY and LIMIT
•	Aggregate functions: COUNT() and AVG()
•	Grouping with GROUP BY and HAVING
•	Table joins to retrieve related records
•	Date-based filtering
Key Queries
•	Retrieve patient and doctor details for appointments.
•	Count appointments per doctor and prescriptions per patient.
•	Find doctors by specialization and experience.
•	Identify the most expensive medicines.
•	Calculate average medicine prices by category.
•	Filter patients by age and city.
•	Retrieve completed appointments and medicines within a specified expiry-date range.
Tools & Technologies
•	SQL
•	Relational database management system
Outcome
Gained hands-on experience in SQL querying, database schema modification, data filtering, aggregation, and joins through practical healthcare database exercises.
