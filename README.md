# Hospital Database Management System (SQL)

## Project Overview

A SQL-based project focused on managing hospital data and retrieving meaningful information through queries. The database includes doctors, patients, medicines, surgical items, appointments, and prescriptions.

## Database Tables

**Doctors:** Stores doctor IDs, names, specializations, years of experience, and contact details.

**Patients:** Contains patient names, age, gender, and city.

**Medicines:** Stores medicine names, categories, prices, and expiry dates.

**Surgical Items:** Contains surgical equipment details, types, costs, and stock information.

**Appointments:** Maintains relationships between patients and doctors, along with appointment dates and statuses.

**Prescriptions:** Stores prescription records linked to patients, doctors, and medicines.

## SQL Concepts Used

Practiced database creation and data insertion, schema modification using `ALTER TABLE`, data filtering using `WHERE`, `LIKE`, and `BETWEEN`, sorting and limiting results using `ORDER BY` and `LIMIT`, aggregate functions such as `COUNT()` and `AVG()`, grouping with `GROUP BY` and `HAVING`, table joins to retrieve related records, and date-based filtering.

## Key Queries

Retrieved patient and doctor details for appointments, counted appointments per doctor and prescriptions per patient, found doctors based on specialization and experience, identified the most expensive medicines, calculated average medicine prices by category, filtered patients by age and city, and retrieved completed appointments and medicines within a specified expiry-date range.

## Tools & Technologies

- SQL
- Relational Database Management System (RDBMS)

## Outcome

Gained hands-on experience in SQL querying, database schema modification, data filtering, aggregation, and joins through practical healthcare database exercises.
